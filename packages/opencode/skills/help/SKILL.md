# How opencode Works

opencode enhances Claude Code with intelligent skills that activate automatically.

## What Happens Automatically

| When You...            | opencode Automatically...                       |
| ---------------------- | ----------------------------------------------- |
| Give complex task      | Parallelizes and delegates to specialist agents |
| Ask to plan something  | Starts structured planning workflow             |
| Need something done    | Persists until verified complete                |
| Say "stop" or "cancel" | Intelligently stops current operation           |

## Magic Keywords

| Keyword       | Effect                                   |
| ------------- | ---------------------------------------- |
| **ralph**     | Persistence mode — keep going until done |
| **plan**      | Planning interview — scope before coding |
| **team**      | Spawn coordinated worker agents          |
| **tdd**       | Test-driven development — tests first    |
| **autopilot** | Full autonomous execution                |

**Ralph includes parallelism**: When you activate ralph mode, it automatically uses parallel execution where possible.

## Stopping Things

Just say:

- "stop"
- "cancel"
- "abort"
