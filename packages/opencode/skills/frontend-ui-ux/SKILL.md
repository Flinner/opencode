# Skill: frontend-ui-ux

Designer-developer workflow for frontend work.

## Use When

- Building UI components
- Working on responsive layouts
- Design system consistency checks
- Accessibility compliance

## Workflow

### 1. Design Analysis

- Identify component structure
- Note design tokens (colors, typography, spacing)
- Map component hierarchy

### 2. Implementation

- Use semantic HTML elements
- Apply CSS matching design specs
- Ensure responsive breakpoints
- Add accessibility attributes (ARIA labels, keyboard navigation)

### 3. Verification

- Check visual fidelity against reference
- Test at multiple viewport sizes
- Verify keyboard navigation
- Run accessibility audit (axe-core equivalent)

## Design Principles

- **Mobile-first**: Design for smallest screen first, enhance up
- **Progressive enhancement**: Core content works without JS/CSS
- **Semantic markup**: Use proper HTML elements, not divs
- **Accessible**: WCAG 2.1 AA compliance minimum
